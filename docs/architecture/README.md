# Architecture Working Notes

This directory is the home for non-normative architecture working documents and future derived views.

Current authority remains the [accepted System Design](../baseline/Mnemograph_Triadic_Research_Workbench_System_Design_v0.1.md). The [ADR directory](../adr/README.md) contains the decision records that may add or refine architecture direction when explicitly approved.

Appropriate content here includes diagrams, module views, data flows, interface notes and deployment views that help explain or trace the current architecture.

Not appropriate here: accepted normative decisions, secrets, provider selections without an ADR, copied scientific source documents, or implementation claims without evidence.

Traceability expectation: architecture notes should link back to the baseline, ADRs, issues or implementation evidence that justify them.

Phase 0 status: index only, with no additional architecture artifacts yet.
