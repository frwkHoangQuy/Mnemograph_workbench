# mnemograph-domain

Delivery ownership: Delivery D1 - Domain & Contracts.

Distribution: `mnemograph-domain`

Import module: `mnemograph_domain`

This package holds pure domain primitives and the Delivery D1.4
Goal–Plan–Subgoal scoping slice. It supports Goal creation, scoping,
decomposition proposal, user revision, and user approval through the first
entry into `DELIBERATING`.

The package remains standard-library-only. It does not import web frameworks,
database clients, model SDKs, contracts production code, or infrastructure.
Persistence, deliberation behavior, and Subgoal acceptance/reopen behavior are
outside Delivery D1.4.
